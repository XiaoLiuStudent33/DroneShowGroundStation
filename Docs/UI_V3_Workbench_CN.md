# V3 工作台

## 使用
在编辑器中打开 `/Game/Maps/L_GCS_Workbench_V3` 并运行，登录后进入 V3。原始关卡 `/Game/Maps/DroneShowPlatform1` 和默认登录入口仍进入旧工作台。开发版测试账号仍为 123 / 123。

## 隔离边界
- 原 UI 目录、原地图和原地图 external actors 未改写，以本次开始时（包含用户已有修改）的 SHA-256 为基线核对。
- V3 主界面的七个子控件均使用 UI_V3 资产。复制关卡原有 CreateWidget 节点和模块启动入口均指向同一 V3 主类，避免叠加两套界面。
- V3 导航页、遥测筛选、上传仪表板与导入弹窗按当前地图选择 V3 资产。
- 行数据类型、部分列表行和辅助控件仍复用已有类型；材质、地图 Actor 蓝图和业务服务也仍共享。不要修改共享资产来调整 V3 样式，应先复制并替换对应引用。
- 后端控制协议、会话和上传事务继续使用现有实现。

## 排版
顶部品牌和控制链路状态，第二行横向导航；机群列表位于左侧，控制台位于右侧，中间保留地图空间。侧栏随窗口高度伸缩，右侧保留滚动与折叠。选机详情及播放面板沿用现有显示逻辑。删除了固定示例演出时间和演出名称，避免冒充实时数据。

## 维护
`GCSV3EditorLibrary` 是编辑器资源搭建工具。`UnrealGCS/Scripts/build_v3_workbench.py` 会重新生成这版预设布局，后续手工改版后不要随意重跑。运行时由现有 UI Bridge 绑定控件，因此保留 CHILD_* 与 BTN_* 等接口名称。
